Foxmayn Frappe Desktop 0.4.0 (beta): French and Arabic, keyboard and screen-reader basics, polish. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.4.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.4.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **Français et العربية.** The whole app speaks English, French and Arabic: every screen, dialog and message, and the file dialogs the app opens. The first start follows your system's language; change it in Settings > General, in the command palette (Ctrl+K) or on the first welcome page. Arabic lays the app out right to left with an Arabic font (Noto Sans Arabic) and keeps Latin digits. Code, file paths, commands and field changes stay left to right, and text from your sites keeps its own direction.
- **The assistant answers in your language.** Ask in French or Arabic and it replies in that language. Document names, field names and values stay as your site has them.
- **Keyboard shortcuts.** Ctrl+N (Cmd+N on macOS) starts a new conversation from anywhere, Ctrl+, opens Settings and Ctrl+/ lists every shortcut. They work with Arabic, French (AZERTY) and other keyboard layouts.
- **Keyboard and screen readers.** The whole chat works with the keyboard alone. Moving to another screen puts the focus on its title, the conversation actions are reachable with Tab, and Delete on a focused conversation asks to delete it. Colours were checked for contrast in light and dark.
- **Starter prompts.** An empty conversation suggests four questions that suit its profile. Picking one only fills the message box: edit it, then press Enter.
- **Connect apps.** The screen that connects Claude Desktop, Cursor, VS Code, Claude Code and Codex now says "apps" throughout; "the Assistant" is the chat inside this app.
- **Send feedback.** In the sidebar and the command palette: opens a short form on GitHub with the app version, your system and the app's language filled in, and nothing else. It needs a GitHub account.

## Good to know

- The French and Arabic texts are new. Report a wording that reads wrong with **Send feedback** (choose "A translation").
- A few technical details from the app's helper (error details, installer log lines) stay in English.
- Your messages and the data the assistant reads are sent to the provider you choose. Use a local model, or a site set to **Local models only**, to keep them on your computer.
- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.4.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
