Foxmayn Frappe Desktop 0.9.0 (beta): confirmations move into the app, and the two that guarded secrets are no longer needed. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.9.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.9.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **Questions are asked in the app.** Loosening a site's safety rules, replacing a saved site, removing a site that has rules and turning off Local models only now ask in the app's own dialogs instead of a system dialog. Cancel is still the default.
- **Moving a site to another server asks for its sign-in again.** Changing the address on the same server (for example `http://` to `https://`) keeps the saved key or password. On a different server, enter the API key and secret, or the username and password, again: the saved ones are never sent to another server.
- **Dropped files are read directly.** Dropping a file on the message box attaches it without a question. The app reads only the files you drop and never opens a file by its path.
- **Restore cards say what comes back.** Approving a restore now shows the document type and name it brings back, not only "Deleted Document".
- **Prepared reports ask first.** A report run that would start a prepared report on the site (a background job) now needs your approval, like any other change.

## Good to know

- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.9.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
