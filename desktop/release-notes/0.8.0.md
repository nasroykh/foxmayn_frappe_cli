Foxmayn Frappe Desktop 0.8.0 (beta): safer site changes and hardening from a security review. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.8.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.8.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **More changes ask first.** These now ask in a system dialog before anything is sent or saved; No is the default:
  - **Changing a site's address.** The saved API key or password is sent to the new address to check it.
  - **Replacing a saved site.** Its saved sign-in is deleted.
  - **Removing a site that has safety rules.** The rules go with it, and a site added again under that name starts with none.
  - **Turning off Local models only.** The site's data can then reach online model providers.
- **Approval cards show every change.** A text field changed to a number that looks the same (for example "0123" to 123) is now listed. Hidden characters in field names and values (direction marks, zero-width spaces) are shown escaped, so what you approve is what is written.

## Fixed

- **Dropped files:**
  - The "Attach dropped files?" question now has Cancel as its default button.
  - File names with direction-changing characters can no longer display reversed.
  - On Windows, only files on a drive letter are read.
- **Large or crafted files:**
  - An XLSX workbook may now unpack to 16 MB (8 MB per part). A small crafted workbook used to take more than a gigabyte of memory.
  - Activity no longer slows down on a damaged or crafted audit log.
  - The app refuses a model server's answer over 64 MB.
- **Model providers:**
  - A new model provider never reuses a key left in the system keychain by an earlier one with the same name.
  - The cost reported by a model server is trusted only from OpenRouter; other servers use the price table, or show the cost as unknown.

## Good to know

- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.8.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
