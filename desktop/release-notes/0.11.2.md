Foxmayn Frappe Desktop 0.11.2 (beta): the Assistant can look up document types as any user. Not an official Frappe product.

## Update

From 0.10.0 or later: Settings > About > **Install update**, or the button in the update notice.

From an earlier version, or from a terminal:

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.11.2/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.11.2/install-desktop.ps1 | iex"
```

Beta builds are not yet signed by Apple or with a Windows code-signing certificate; the scripts and the in-app update check the download themselves (release signature and SHA-256).

## Fixed

- **"Looked up a document type: Failed".** On a site added with a user who is not an administrator (for example a Sales User), the Assistant could not read any document type's fields. Frappe lets only administrators read DocType records. The Assistant now reads the same field list the ERPNext desk uses, with your Customize Form changes, which every user may read. With an administrator nothing changes. There is no other change.

The embedded ffc MCP server is the one released as ffc v1.21.1.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.11.2-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
