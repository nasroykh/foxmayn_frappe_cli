First public beta of Foxmayn Frappe Desktop: connect your Frappe sites to AI assistants. Not an official Frappe product.

## What it does

- Manage your Frappe sites: add, rename, edit, remove and choose a default.
- Sign in with the browser (OAuth), an API key, or a username and password.
- Connect Claude Desktop, Claude Code, Cursor, VS Code and Codex to a site through the ffc MCP server, and remove the connection again.
- Installs ffc itself from a verified release (signature and SHA-256 checked) when it is not on your machine.

## This build is unsigned

Windows: run `foxmayn-frappe-desktop-0.1.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications. macOS blocks the first launch. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway" (on macOS 14 and older, right-clicking the app and choosing "Open" also works). If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/foxmayn-frappe-desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
