Second beta of Foxmayn Frappe Desktop. Not an official Frappe product.

## What's new

- **ffc updates from the app.** Once a day at start the app now also checks for a newer ffc release. When there is one, it shows a notice with an **Update** button, an entry in the sidebar, and "Update to X" in Settings > ffc helper (Settings > About > "Check for updates" checks right away). Update downloads the release, verifies it exactly as `ffc update` does (signed `checksums.txt`, then SHA-256), and replaces the ffc the app found where it is, so the old one is never left first on your PATH. Restart your connected assistants afterwards so they start the new ffc. An ffc the app should not replace (a build from source, a wrapper script, or a folder it cannot write) is left to `ffc update` in a terminal.
- **No more white flash in dark mode.** The window now follows the theme chosen in the app, not only the system theme, from the first frame and when resizing.

Users of 0.1.0 see a notice for this version in the app; install it over the old one.

## This build is unsigned

Windows: run `foxmayn-frappe-desktop-0.1.1-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway" (on macOS 14 and older, right-clicking the app and choosing "Open" also works). If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
