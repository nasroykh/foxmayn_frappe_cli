Foxmayn Frappe Desktop 0.11.0 (beta): safer approvals for bulk updates and copies. Not an official Frappe product.

## Update

From 0.10.0 or later: Settings > About > **Install update**, or the button in the update notice.

From an earlier version, or from a terminal:

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.11.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.11.0/install-desktop.ps1 | iex"
```

Beta builds are not yet signed by Apple or with a Windows code-signing certificate; the scripts and the in-app update check the download themselves (release signature and SHA-256).

## Changed

- **Bulk updates show every document.** Before you approve a `bulk_update`, the app reads each document and shows its field changes, one document after another, the way a single update already did. Each document is updated only if nobody saved it after the card was shown; a document changed in the meantime is left alone, the others are saved, and the assistant is told to check with you before trying again. A request that names a document twice, more than 200 documents, or a document the app cannot read is refused before any card.
- **Copies and amendments show what they set.** The card for duplicating or amending a document lists every field the request sets, next to the original's value, and the new document is created only from the version you were shown.
- Every card and message of this change is in English, French and Arabic.

The embedded ffc MCP server is the one released as ffc v1.21.0.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.11.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
