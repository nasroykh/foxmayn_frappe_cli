Foxmayn Frappe Desktop 0.7.0 (beta): safety rules and an activity log. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.7.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.7.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **Safety rules for each site.** Sites > a site's menu > **Safety rules**: choose **Read only**, **Ask before risky changes** or **Custom** (when to ask, and the document types, tools and server methods allowed or refused). The rules apply to everything that uses ffc on the site: the Assistant and the connected apps such as Claude Desktop and Cursor. They are saved in the ffc config file, which keeps its comments.
- **Opening access asks first.** A change that lets the Assistant and the apps do more (read only off, fewer questions, a limit lifted, a refusal removed, a sensitive document type such as User made writable, a server method that runs code made callable) is confirmed in a system dialog that lists what it opens. A change that only narrows is saved at once.

- **Activity.** A new screen lists what the Assistant and the connected apps did on your sites through ffc, newest first: when, which app, which site, what, the result and the duration. Filter by site, app, result and period; open a row for the details. "See activity" under an Assistant answer opens the screen for that answer. It only reads the log.

## Fixed

- **Dropping files on Windows.** The "Attach dropped files?" question never took its answer on Windows and gave up after 10 minutes. It now shows Yes and No and works.

## Good to know

- Rules written by hand that this screen cannot show faithfully (a blank list entry, YAML anchors or merge keys) are refused; edit those in the config file.
- The next ffc release also treats an allow list with a blank entry as a config error (it used to mean no limit); this app already does.
- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.7.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
