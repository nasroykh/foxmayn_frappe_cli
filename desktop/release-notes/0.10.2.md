Foxmayn Frappe Desktop 0.10.2 (beta): security fixes. Not an official Frappe product.

## Update

From 0.10.0 or later: Settings > About > **Install update**, or the button in the update notice.

From an earlier version, or from a terminal:

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.10.2/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.10.2/install-desktop.ps1 | iex"
```

Beta builds are not yet signed by Apple or with a Windows code-signing certificate; the scripts and the in-app update check the download themselves (release signature and SHA-256).

## Fixed

- **Spreadsheet attachments.** A malformed or hostile `.xlsx` file could crash the app or make it use a lot of memory while it was read (excelize GO-2026-6684, GO-2026-6685, GO-2026-6688, GO-2026-6689). The reader is updated to the fixed version.
- **Certificate checks.** Built with Go 1.27.3, which distrusts compromised intermediate certificates when connecting to sites and AI providers (GO-2026-6809).
- The embedded ffc MCP server uses mcp-go v1.3.0 (protocol fixes; no change to tools or approvals).

Nothing else changes.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.10.2-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
