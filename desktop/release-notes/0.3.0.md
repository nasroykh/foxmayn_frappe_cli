Foxmayn Frappe Desktop 0.3.0 (beta): profiles, more providers, cost and history. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.3.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.3.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **Profiles.** Five built-in presets (Explore, Accounts helper, Site admin, Data entry, Local model) set the tools, the mode and the instructions for a conversation. Duplicate one to make your own, with a step limit from 1 to 100. A profile can only narrow what the site allows, never widen it, and a profile that is read only shows a **Read only by profile** badge. **Show what the model gets** lists the instructions and tools the next answer starts with.
- **Site settings.** Instructions for each site, and **Local models only**: conversations on that site may use only a model server on your computer. Hosted providers and Ollama cloud models are refused.
- **OpenAI and Google Gemini.** Two new providers with an API key. Providers are tied to their own hosts, the app does not read provider keys from environment variables, and it never follows a redirect to another host.
- **Sign in with OpenRouter.** Allow a key in your browser instead of pasting it. The key goes straight to the keychain.
- **Cost.** Each run and each conversation shows its tokens and a cost, from the provider's own figure (OpenRouter) or the app's built-in price table (Anthropic, OpenAI, Gemini; prices read from the official pages on 2026-10-09). A model that is not in the table shows **cost unknown**, and the total then reads "at least". Models on your computer show tokens only.
- **Titles.** After the first answer the model names the conversation. **Rename** it yourself and the name stays.
- **History.** Search messages (Ctrl+Shift+F), pin, archive, and choose to delete old conversations after 90 or 30 days (pinned ones are kept). Settings > Assistant > History.
- **Export and import.** Save a conversation as JSON or Markdown, without keys. Import a JSON export as a new conversation: it starts read only, and the model sees the old messages only as untrusted text, never as its own earlier turns.
- **Safer text from the site.** Tool results and site details reach the model inside blocks marked untrusted, with the model told to treat them as data.
- **Attachments.** Drop, choose or paste files into a message: text, CSV, JSON and XLSX (sent as CSV per sheet), and PNG, JPEG, WebP and GIF images for models that read them (Claude, OpenAI, Gemini; not OpenRouter or local models yet). Up to 10 MB a file and 5 files a message. The model gets a file's text as untrusted data. PDF is not supported yet.

## Good to know

- Your messages and the data the assistant reads are sent to the provider you choose. Use a local model, or a site set to **Local models only**, to keep them on your computer.
- Costs are estimates from the price table's date. Prices change; the table is built into the app.
- Conversations from 0.2.0 open as before and count as tokens only.
- Not yet tried against the live OpenAI, Gemini or OpenRouter sign-in services. It was tested with recorded responses and fake servers, so report anything odd.
- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.3.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
