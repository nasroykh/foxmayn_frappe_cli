Foxmayn Frappe Desktop 0.2.0 (beta): the Assistant. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.2.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.2.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **The Assistant.** A new screen where you chat about one of your sites. The assistant reads documents and lists through ffc's tools and answers from what it finds. You see each tool it uses, and **Stop** (or Esc) ends a run at once.
- **Your choice of model.** Anthropic or OpenRouter with an API key, Ollama or LM Studio running on your computer (found automatically), or any server that speaks the OpenAI API at an address you give.
- **Safe by default.** Every conversation starts as **Read only**: the assistant is not even given the tools that change data. Switch a conversation to **Ask before changes** and each create, update, delete or cancel waits for your **Approve** or **Decline**. A card shows the exact request, and for an update the field changes. If the document changed on the site since you looked, the update is refused rather than overwriting it. Declining is always safe.
- **Your site's rules still apply.** Sensitive DocTypes, denied DocTypes and methods, and read-only sites are enforced exactly as for Claude Desktop or Cursor. After 25 tool calls in one run the assistant pauses until you press **Continue**.
- **Audited.** Every tool call is in ffc's audit log (`mcp-audit.jsonl`) with the client `foxmayn-desktop` and a run id that groups one question.
- **Keys stay in the keychain.** API keys are stored in the Windows Credential Manager or the macOS Keychain. The app window never gets a key back, only the last four characters.
- **History stays on your computer.** Conversations are saved in `assistant.db` in the app's data folder (`%AppData%\Foxmayn Frappe Desktop` on Windows, `~/Library/Application Support/Foxmayn Frappe Desktop` on macOS). Delete a conversation to remove it.
- **Connect apps.** The old Assistants screen is now called **Connect apps**; it works as before.

## Good to know

- Your messages and the data the assistant reads are sent to the provider you choose. Use a local model to keep them on your computer.
- The assistant cannot call arbitrary server methods, and long tool results are cut before the model sees them.
- No separate ffc install is needed for the Assistant: the app runs ffc's own code inside itself, at the version it was built with. **Connect apps** still uses the installed ffc, as before.
- Not in this release, planned for later: profiles and presets, searching old conversations, cost figures, attachments and signing in to OpenRouter in the browser.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.2.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
