Foxmayn Frappe Desktop 0.6.0 (beta): simpler screens in all three languages. Not an official Frappe product.

## Install or update from a terminal (recommended)

Beta builds are not yet signed by Apple or with a Windows code-signing certificate. Installing from a terminal skips the macOS and Windows security screens; the scripts check the download themselves (SHA-256, and on macOS also the release signature when OpenSSL 3 is installed).

macOS (Terminal):

```bash
curl -fsSL https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.6.0/install-desktop.sh | sh
```

Windows (PowerShell or cmd.exe):

```powershell
powershell -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/nasroykh/foxmayn_frappe_cli/desktop-v0.6.0/install-desktop.ps1 | iex"
```

The command closes the installed app if it runs, installs this version over it and opens it again.

## What's new

- **Simpler profiles.** The profile editor asks only what most people set: a name, whether the assistant may change things, what it works with (in plain words) and instructions. Lists of tools, DocTypes and methods, server methods, history and the step limit are under **Advanced settings**.
- **A calmer chat header.** The conversation's title stays readable. One **Ask before changes** switch replaces the two buttons; Rename and "Show what the model gets" are in the **⋯** menu.
- **Clearer approvals.** An update shows a table of each field with its value before and after. The exact request is under **Technical details**.
- **Plain words.** Tool rows say what the assistant did ("Read a document", "Ran a report") instead of internal tool names, and the suggested questions avoid jargon.
- **Tidier lists.** Import and the archive are in the **⋯** menu above the conversations, and Delete is in each conversation's menu. Connect apps shows cards of the same height and "Connect anyway" for an app not found. Sites says **Test connection**.
- **Arabic and French.** Fixes for right-to-left (keyboard keys, the send arrow, masked keys), shorter French labels, and many clearer Arabic and French texts.

## Good to know

- The French and Arabic texts still wait for a review by native speakers. Report a wording that reads wrong with **Send feedback**.
- Still an unsigned beta: see the install notes above.

## Manual download

Windows: run `foxmayn-frappe-desktop-0.6.0-windows-amd64-setup.exe`. It installs for your user only (no administrator rights). If SmartScreen blocks it, choose "More info", then "Run anyway".

macOS (Apple silicon and Intel): open the `.dmg` and drag the app to Applications, replacing the old one. macOS blocks the first launch of a browser download. Open it once, then go to System Settings > Privacy & Security and choose "Open Anyway". If macOS says the app "is damaged", remove the download quarantine in Terminal: `xattr -dr com.apple.quarantine "/Applications/Foxmayn Frappe Desktop.app"`.

## Verify

`checksums.txt` lists the SHA-256 of each file, and `checksums.txt.sig` is its signature with the ffc release key. Each file also has a build-provenance attestation (`gh attestation verify <file> --repo nasroykh/foxmayn_frappe_cli`).
